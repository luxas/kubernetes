## 2.1 How a conditional decision reaches (or cannot reach) an `Authorize` caller

The census uses these mechanisms, which hold on HEAD:

- **M1. Not requested.** On `Authorize`, none of the built-in authorizers asks for conditions.
  RBAC, Node, ABAC, AlwaysAllow/Deny and privileged-groups lift `Authorize` (`rbac.go:134`,
  `node_authorizer.go:111`, `abac.go:246`, `builtin.go:41,84,108`). The webhook `Authorize` sends a SAR
  without `authorizationOptions`. If the webhook answers with a `conditionalDecision` anyway,
  `webhook.go:264-267` returns `FailureDecision()` plus the error
  `"webhook subject access review returned unrequested conditional decision"`. An explicit `denied`
  takes precedence (`webhook.go:262-263`). Union `Authorize` (`union.go:76-97`) and the
  reload/metrics wrappers call `Authorize` on their children. So **every `Authorize` caller gets an
  unconditional answer, and the gate does not affect this.** `UnconditionalPartsOrFailClosed` is
  never used for this (see §1). In callers that treat "error and not Allow" as a server error
  (`authorization.go:115-118`, `authorization.go:211-214`), an unrequested conditional webhook
  answer therefore produces a 500, not a 403.
- **M2. Requested only when evaluation is possible.** The webhook `ConditionsAwareAuthorize`
  advertises `HandledDecisionTypes` only if an ACR reviewer is configured (`webhook.go:286-292`).
  In kube-apiserver that requires the gate and a `conditionsReview` config (`reload.go:188-210`).
  Delegating authorizers (aggregated servers) always get an ACR client
  (`staging/src/k8s.io/apiserver/pkg/server/options/authorization.go:206`), but those servers have no
  classifier (see M3), so their filter never calls `ConditionsAwareAuthorize`.
- **M3. Filter selection** (`staging/src/k8s.io/apiserver/pkg/server/config.go:1077-1087`).
  `WithConditionsAwareAuthorization` is installed only when all three hold: the gate is on, a
  classifier is set, and the `AuthorizationConditionsEnforcer` plugin is enabled. Only kube-apiserver
  sets the classifier (`pkg/controlplane/apiserver/config.go:248-250`, gate-guarded), and the
  classifier returns true only for resource requests with admission verbs that are not excluded
  from admission (`config.go:299-321`). Otherwise the legacy `WithAuthorization` is installed.
